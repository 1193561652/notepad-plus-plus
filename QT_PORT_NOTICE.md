# Notepad++ for Qt: attribution and licensing

This repository's `qt-port` branch is an independent Qt port derived from
[Notepad++](https://github.com/notepad-plus-plus/notepad-plus-plus), with
Notepad++ v8.4.6 as its compatibility baseline. It is not an official
Notepad++ release and is not maintained by the original Notepad++ project.
