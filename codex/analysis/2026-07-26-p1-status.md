## 原版对照要点

- UDL 的 28 组列表不能直接依次传给 Scintilla。原版将其中 13 组转换为
  `userDefine.*` 属性，其余 15 组按固定顺序作为关键词集合。
- v8.4.6 的 Scintilla 将 `KEYWORDSET_MAX` 扩到 30，QScintilla 2.13.3
  默认值为 8；只加入 LexUser 会越界。
- UDL 旧 XML styleID 与 LexUser 运行时 styleID 不同。运行时需映射，
  写回必须保留原 XML ID。
- Finder 导航位置是 UTF-8 文档字节偏移，不能用 QString 索引代替。

## 剩余风险

- Finder 取消在 UI 线程中协作执行，单次网络 I/O 阻塞不能立即取消。
- 重命名多候选或时间戳被重写时会退回删除提示。
- 打印布局依赖打印驱动，需要运行验证页眉页脚和边距。
- UDL 缓存按 lexer 实例隔离，释放策略仍与原版一样依赖进程生命周期。
