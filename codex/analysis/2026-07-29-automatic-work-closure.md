# 非人工工作最终收口

日期：2026-07-29

## 范围

按用户决定排除插件系统和大文件方案 B。对其余源码占位、功能索引、语言资源和
自动验证进行复核，完成所有当前能够在本机通过代码或自动化运行闭环的工作。

## 审计结论

- 非插件菜单中不存在未实现的 disabled 占位；唯一通用占位是
  `Import plugin(s)...`。
- 早期文档中的编码、项目查找、右键菜单、工具栏、UDL、Function List 等缺项
  已被后续实现取代，不再是当前待办。
- Find、Preferences 和主窗口的简体中文、浅色/深色、100%/150% 缩放现在进入
  自动测试矩阵。
- 当前没有边界明确且能在本机自动实施的剩余代码待办。

## 仅剩外部边界

这些项目无法在当前 Windows x64 工作区内自动完成，不属于待确认代码：

- Linux/macOS 实机构建和运行。
- 真实 UNC/SMB 端点断线与恢复。
- 物理打印机纸张输出。
- 32 位 Qt/MinGW 实机构建；当前编译器为 `x86_64-w64-mingw32`。
- 真实 2 GiB 以上文件压力测试；常规测试已覆盖分块编解码和阈值边界。
- 原版与 Qt 版的最终主观像素观感。
