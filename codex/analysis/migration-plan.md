# Qt 移植计划

更新日期：2026-07-22

## 排序原则

1. 优先完善当前高完成度的基础功能。
2. 如果某个功能是很多功能的依赖，即使它本身不是 UI 可见功能，也应提前。
3. 配置 XML 体系是菜单、快捷键、会话、语言、样式、查找历史、偏好设置和插件边界的基础，因此放在最前面。
4. 每个阶段只指定有限范围，完成后验证并更新 `codex/` 索引。

## 阶段 0：配置 XML 与资源兼容基础

状态：已完成当前基础范围。详见 `codex/analysis/stage-1-xml-configuration.md` 与 `codex/changes/2026-07-22-stage-1-xml-resources.md`。

目标：先建立稳定的配置读写地基，避免后续功能各自写临时配置逻辑。

| 优先级 | 功能 | 原因 | 主要工作 |
| --- | --- | --- | --- |
| P0 | 配置目录结构 | 所有配置功能基础 | 对齐 `plugins/`、`themes/`、`autoCompletion/`、`localization/`、`backup/` 等目录 |
| P0 | XML 读写框架 | 完全兼容要求核心 | 保证 TinyXml 读写中文路径、编码、默认文件复制和错误处理 |
| P0 | `config.xml` | GUI、编辑器、历史、备份等基础 | 建立节点级索引，优先做到不丢未知节点/属性 |
| P0 | `session.xml` | 文件恢复和双视图基础 | 对齐 `mainView`、`subView`、`File`、位置、编码、备份字段 |
| P0 | `langs.xml` | 语法高亮、注释、自动完成基础 | 对齐语言名、扩展名、注释符、关键字 |
| P0 | `stylers.xml` | 语法样式和主题基础 | 对齐 lexer、styleID、全局样式、字体、颜色 |
| P0 | `shortcuts.xml` | 菜单、快捷键、宏基础 | 先建立读取和保持写回，再逐步绑定命令 |
| P0 | `contextMenu.xml` | 编辑器右键菜单基础 | 先建立读取和结构保持，具体菜单项后续接入 |
| P0 | `toolbarIcons.xml` | 工具栏兼容基础 | 先建立索引，决定 Qt 图标映射策略 |
| P0 | `nativeLang.xml` / localization | UI 文案基础 | 对齐语言文件路径、切换和默认语言 |

## 阶段 3：高完成度 UI 和视图功能

| P3 | 快捷键基础 | 依赖命令映射 | 接入 `shortcuts.xml`，处理冲突和写回 |
| P3 | 工具栏 | 依赖工具栏配置策略 | 按钮状态、图标、显示隐藏配置 |
| P3 | 双视图 | 依赖 Buffer 生命周期 | split、move、clone、活动视图同步 |
| P3 | 文档地图 | 已有面板 | 滚动同步、视图切换、显示隐藏配置 |
| P3 | 函数列表 | 已有面板 | 解析范围、刷新时机、点击跳转 |
| P3 | 文件浏览器 | 已有面板 | 根目录、双击打开、会话保存 |
| P3 | 偏好设置已实现页面 | 依赖配置写回 | 完善已有页面，stub 后置 |

## 阶段 4：原版 UI 一致性检验

状态：已完成代码级 UI 结构一致性审计。详见 `codex/analysis/stage-4-ui-consistency-audit.md` 与 `codex/changes/2026-07-22-stage-4-ui-consistency.md`。

目标：单独检验原版 UI 和 Qt 移植版 UI 的一致程度。此阶段不以补齐全部业务功能为目标，而是确认 UI 骨架、可见入口、布局、菜单分组、快捷键展示、状态栏栏位和主要对话框结构已经对齐。

| 优先级 | 检验项 | 原因 | 主要工作 |
| --- | --- | --- | --- |
| P4 | 菜单一致性 | UI 主入口 | 对照原版菜单结构、分组、顺序、可见文本和启用/禁用状态 |
| P4 | 工具栏一致性 | 高频操作入口 | 对照图标、顺序、按钮状态、显示隐藏配置 |
| P4 | 状态栏一致性 | 编辑状态反馈 | 对照语言、长度、行列、EOL、编码、INS/OVR 等栏位 |
| P4 | 标签栏一致性 | 文档管理入口 | 对照脏标记、关闭按钮、Tab 行为、双击和右键菜单 |
| P4 | 主编辑区一致性 | 核心体验 | 对照行号、边距、书签、折叠、缩进线、空白符和主题样式 |
| P4 | 对话框一致性 | 原版交互习惯 | 对照查找替换、偏好设置、关于、跳转行等主要对话框结构 |
| P4 | 停靠面板一致性 | 侧栏体验 | 对照文件浏览器、文档地图、函数列表、查找结果等面板 |
| P4 | 配置驱动 UI 状态 | 行为一致基础 | 验证 UI 显示/隐藏和 checked 状态从 XML 配置初始化 |
| P4 | UI 占位标记 | 后续开发衔接 | 标记已完成 UI 但实际功能缺失的入口，写入功能差异清单 |

阶段完成标准：

- 原版主要 UI 入口在 Qt 版中都有对应位置。
- 未实现业务功能的 UI 入口应明确标记为占位或禁用，避免误导。
- 形成 UI 一致性报告，保存到 `codex/analysis/`。
- 更新功能差异清单，区分“UI 已完成但逻辑未完成”和“UI 也缺失”。
