## 完成定义

每个插件至少需要：

1. x86 清单身份和版本；
2. 源码存在性、对应 revision、许可证与维护状态；
3. 可确认的 `NPPM_*`、`NPPN_*`、`SCI_*`、Win32、Dock、线程和运行时依赖；
4. 主窗口加双 Scintilla 代理 HWND 模型的适用性；
5. A/B/C/D/U 初评、证据和未验证项。
