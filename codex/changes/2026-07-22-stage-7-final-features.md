# 阶段七：后置功能基础闭环

日期：2026-07-22

## 完成内容

- 接入 Qt PrintSupport、`QsciPrinter`、打印对话框和直接打印。
- 将宏录制对象从视图动态属性迁移为主窗口明确所有权，支持录制期间切换标签后停止，并在退出时安全释放。
- 增加列编辑基础对话框：文本或递增数字可批量插入选中行的同一列。
- 增加高频行排序和文本处理：字典排序、忽略大小写排序、反转、删除空行、修剪、TAB 转空格。
- 新增 `UserLangDesc` 和 `UserDefinedLexer`，只读加载 `userDefineLang.xml` 并提供基础 UDL 高亮和扩展名自动识别。
- Language 菜单动态列出用户自定义语言。
- 插件扫描兼容根目录和一级插件子目录，规范路径去重，并在主窗口析构时完整清理插件。
- 插件系统构建选项默认关闭；接口保留，可通过 CMake 选项显式启用。
- 为旧 MinGW 7.3 + 新版 CMake 的 AUTOMOC 组合关闭编译器预定义探测，避免 `moc_predefs.h` 生成失败。

## 验证结果

- CMake 配置成功。
- Debug 构建成功：`[100%] Built target notepadpp-qt`。
- Windows GUI 冒烟启动成功，进程稳定运行 3 秒。
