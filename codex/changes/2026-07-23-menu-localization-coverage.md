# 菜单本地化覆盖修复

日期：2026-07-23

## 问题

部分菜单保持英文，原因包括语言解析器只读取首个 `Entries` 分组、翻译应用早于停靠面板创建，以及少数静态动作缺少稳定 `objectName`。

## 修改

- `NativeLangSpeaker` 遍历全部 `Entries` 和 `Commands` 兄弟分组。
- 首次 `applyNativeLang()` 延后到菜单、工具栏和停靠面板全部创建完成后。
- 补充排序、最近文件清理、普通文本和插件状态动作的稳定标识。
- 支持标准工具栏标题翻译和英文恢复。
- 扩充简体中文 XML，覆盖当前主窗口的静态菜单、动作和面板。
- 补齐偏好设置 19 个页面的控件、下拉选项、数值单位和标准按钮翻译。
- 偏好设置关闭后按当前语言重新创建，避免运行时切换后复用旧语言控件。
- `NativeLangSpeaker::changeDlgLang()` 支持 `QComboBox` 条目和 `QSpinBox` 后缀。

## 验证

- 简体中文 XML 通过 XML 解析校验。
- 源码 `objectName` 与语言资源反查无已知静态 UI 缺项。
- 偏好设置控件标识与语言资源反查缺失数为 0。
- `cmake --build build -j 4` 构建通过。
