# 2026-07-28 UI 完善

## 修改范围

- 工具栏自定义图标配置。
- 标准工具栏顺序、按钮和尺寸。
- 深色模式 palette 与 Qt Widgets 样式。
- UI 捕获工具的显式 light/dark 模式。

## 行为变化

- 重启时读取用户目录 `toolbarIcons.xml`，在
  `toolbarIcons/<图标集>/` 中按原版名称加载 `.ico`。
- 自定义图标缺失时保持内置图标，不要求完整图标集。
- 深色模式运行时切换覆盖所有顶层对话框和子控件。
- 编辑器语法和背景仍由主题文件控制，避免深色 UI 覆盖用户配色。
