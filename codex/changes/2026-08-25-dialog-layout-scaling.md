# 对话框布局与缩放修正

日期：2026-08-25

## 范围

- 查找/替换五个页签不再使用会裁剪选项区的固定像素高度；初始尺寸由 Qt 布局和
  当前平台字体共同确定，仍保留原版 `382 x 200 DLU` 的结构与最小宽度。
- 查找/替换窗口恢复原版横向调整大小的约束：宽度可增加，高度保持初始值，并显示
  Qt 跨平台尺寸手柄。
- 首选项继续使用原版 `560 x 235 DLU` 和子页坐标作为布局基线，但 DLU 到像素的
  换算改为根据应用字体计算，并设置跨平台上下限。
- 首选项分类栏按翻译后的最长项目扩展；绝对坐标子页中的标签和复选框在显示时按
  翻译文本补足可用宽度。
- “常用”页的标签栏选项恢复为接近原版的单列结构；“自动完成”页补充原版控件 ID
  到 Qt `objectName` 的精确本地化映射。
- 主窗口状态栏恢复原版鼠标交互：单击 `INS/OVR` 切换输入模式；双击位置/文档大小
  打开转到行/文档摘要；双击或右键语言、换行符、编码区弹出对应菜单。

## 验证

- `UiParityCapture` 会逐页检查查找窗口中的可见控件未超出窗口边界。
- UI 回归验证查找窗口只能横向扩展，并验证 `INS/OVR` 点击会同步修改 Scintilla
  覆盖输入状态。
- 首选项 19 个页面会检查可见控件边界，并禁止页面依赖横向滚动才能看到内容。
- 覆盖简体中文 100%/150%、暗色 100%/150% 和日语 100% UI 捕获。

原版布局来源见 `v8.4.6`：

- `PowerEditor/src/ScintillaComponent/FindReplaceDlg.rc`
- `PowerEditor/src/WinControls/Preference/preference.rc`
