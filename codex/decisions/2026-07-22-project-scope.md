# 2026-07-22 项目范围确认

## 背景

在建立代码知识库前，确认 Qt 移植项目的主线范围、配置兼容目标、插件近期目标和验证策略。

## 结论

- 仓库根目录是唯一主线开发目录。
- 功能开发范围在完成相关功能分析后再指定有限范围。
- 配置兼容要求为完全读写兼容。
- 插件不属于近期目标，但代码中必须留出接口和平台适配边界。
- 允许建立 `codex/` 初始代码知识库和索引。
- 每个独立功能完成后至少验证；阶段开发过程中根据需要执行构建。

## 影响范围

- 后续代码修改默认只作用于当前分支工作树。
- 原版 v8.4.6 通过 Git tag 只读查阅。
- 配置系统相关修改需要特别谨慎，不能破坏 XML 结构和目录兼容性。
- 插件代码应保持接口设计，但避免近期投入完整插件功能实现。

## 后续注意事项

- 需要继续完善 `codex/` 下模块和功能索引。
- 分析功能时，应先确认原版行为，再评估 Qt 当前实现差异。
- 如插件构建选项影响当前开发，应单独评估 `ENABLE_PLUGIN_SYSTEM` 默认值。
