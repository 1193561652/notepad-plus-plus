# 延期待决：大文件模式与 Boost.Regex 全语义（部分已解除）

日期：2026-07-25

## 决策

该记录创建时以下两项被延期：

1. 原版 Notepad++ 大文件模式及其阈值、降级策略、UI 提示和功能限制。
2. Boost.Regex 的完整语法、替换表达式、错误行为和边界语义兼容。

2026-07-25 后续决策已解除第 2 项延期，并采用自建静态 QScintilla +
`SCI_OWNREGEX` + 原版 Boost.Regex 适配层方案。详见
`2026-07-25-boost-regex-static-integration.md`。

2026-07-26 已解除第 1 项延期。大文件模式确定采用完整复刻 v8.4.6 的方案 A；
方案缺陷和方案 B 后续可选优化已记录在
`2026-07-26-large-file-mode-v846-parity.md`。该决策表示目标行为已确定，
方案 A 已于 2026-07-26 完成；方案 B 仍为后续可选优化。

## 当前行为

- Qt 版已使用带原版选项的 QScintilla 大文档和分块 I/O 路径。
- 当前文档与跨文档/文件搜索均已统一到 Scintilla Boost.Regex；Finder UI、
  取消/进度和大目录性能仍是其他层面的差异。

## 已完成的实现范围

- 大文件模式：按新决策实现固定 200 MiB 阈值、原版降级行为、Scintilla 大文档
  选项、分块加载/保存和约 2 GiB 分支。
Boost.Regex 的旧前置分析已由后续决策取代。大文件模式不得在其他功能修改中
脱离自动测试和真实源码核验而被扩展声明。
